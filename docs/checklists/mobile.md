# 휴대폰 점검표 (04 T1-9)

실제 휴대폰에서 하나씩 확인합니다. 통과하면 `[x]`로 바꾸고, 기기와 브라우저를 적습니다.

- 점검한 기기·브라우저: (예: 갤럭시 S23 / 삼성 인터넷, 아이폰 13 / 사파리)
- 점검한 날:
- 주소: https://aud9855.github.io/digimon-tamers-blue-card/

## 열기와 설치

- [ ] 링크로 열린다
- [ ] 홈 화면에 추가할 수 있고, 아이콘(파란 카드)이 보인다
- [ ] 홈 화면에서 열면 주소창 없이 세로 화면으로 열린다
- [ ] 비행기 모드에서 홈 화면 아이콘으로 열린다 (한 번 연 뒤)

## 화면

- [ ] 세로 화면에서 위아래·좌우가 잘리지 않는다 (노치·홈 바 영역 포함)
- [ ] 가로로 밀리거나 확대되지 않는다 (두 번 누르기, 두 손가락 벌리기)
- [ ] 글자가 읽을 만한 크기다 (카드 설명 포함)
- [ ] 버튼이 손가락으로 누르기 충분히 크다 (턴 끝, 진화, 지도 칸)

## 전투 조작

- [ ] 카드를 위로 끌어 올려 낼 수 있다
- [ ] 카드를 적 위로 끌어 놓아 낼 수 있다
- [ ] 카드를 누른 뒤 적이나 "여기를 눌러 내기"를 눌러 낼 수 있다
- [ ] 낼 수 없는 카드는 흐리고, 끌어지지 않는다
- [ ] 카드를 길게 누르면 크게 보인다
- [ ] 메모리를 넘겨 쓰려 하면 "적 가속 +N" 경고가 먼저 보인다
- [ ] 진화 컷인, 피해 숫자, 카드 슬래시가 끊기지 않고 보인다
- [ ] 연출 중 화면을 누르면 건너뛴다. 설정에서 연출을 끌 수 있다

## 그 밖

- [ ] 휴대폰 뒤로 버튼(또는 뒤로 밀기)을 눌러도 게임에서 나가지지 않는다
- [ ] 전투 도중 앱을 닫았다가 다시 열면 같은 자리에서 이어진다
- [ ] 다른 앱으로 갔다 와도 상태가 그대로다
- [ ] 1막을 처음부터 끝까지 할 수 있다 (승리 또는 패배까지)
